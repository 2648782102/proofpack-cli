# Contributing

Proofpack is early-stage. Please open an issue before proposing a large feature so product scope and safety implications can be discussed.

- Keep changes focused and explain user impact.
- Do not include repository content, real command output, tokens, or personal paths in fixtures.
- Add or update tests and the relevant product/CLI/security document.
- Run `npm run check`, `npm test`, and `npm run build` before submitting.
- Do not add telemetry, network calls, implicit command execution, or state-changing Git behavior without an explicit design decision.
